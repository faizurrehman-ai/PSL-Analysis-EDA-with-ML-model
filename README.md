# PSL Analysis: EDA & Machine Learning Model 🏏

A comprehensive data analysis and predictive modeling project focused on the **Pakistan Super League (PSL)**. This project explores historical match data using visualization and machine learning to uncover trends and predict outcomes.

## 🚀 Features
* **Exploratory Data Analysis (EDA):** Deep dive into team performances, player stats, and venue trends.
* **Visualizations:** Built using **Seaborn** and **Matplotlib** for high-quality insights.
* **ML Model:** Implements **XGBoost** and **RandomForest** to predict match winners or scores.
* **Data Source:** Analyzed using `.csv` datasets.

## 🛠️ Tech Stack
* **Language:** Python 3.12
* **Libraries:** Pandas, NumPy, Scikit-Learn, XGBoost, Seaborn, Matplotlib

## 📊 Quick Results
* Achievement of high accuracy in match prediction using optimized hyper-parameters.
* Visualized top run-scorers and wicket-takers across all PSL seasons.
